Publish free with GitHub Pages:
1. Sign in to https://github.com or create an account.
2. Create a new PUBLIC repository, for example: monalisa-bhanu-wedding
3. Upload index.html and the entire assets folder (with all five images).
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder / (root), then Save.
7. Wait a minute or two; GitHub will show the public website URL in Settings → Pages.
